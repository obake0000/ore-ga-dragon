# ゲームの原本と公開版

2026-11-18：入口と2つのゲームを分離。

- `index.html` は選択用の静止ページ。ゲーム本体として編集しない。
- `source/game.html` は公開リポジトリ内の全機能の原本。既存の狭い置換パッチはこのファイルに適用してから2版を作り直す。
- `honpen.html` はレッドドラゴン固定・シナリオ1の4章。`models/honpen-manifest.json` の依存模型のみ読み、PCでも軽量版を使う。
- `musou.html` は22キャラ・シナリオ2〜12。
- `story.html` は以前からの物語資料。ゲーム版と取り違えない。

再生成（PythonとPillowが必要）：
```
python scripts/build_musou.py
python scripts/build_honpen.py
```

本編の専用模型名簿は本体の章・敵の依存情報に、`scripts/honpen-dependencies.json` の動的依存を加えて作る。新しい敵・変身・仲間を本編に追加したら、この依存と4章の全波・ボス変身を再検証する。軽量版がなければビルドを停止する。

セーブは版ごとに分離。旧キーを消さず、対応するシナリオの保存だけを移行する。

共有制作フォルダ `C:/lo/ドラゴンゲーム/index.html` は全機能の編集原本を維持している。共有の `entry.html` と `honpen.html` / `musou.html` は公開版の控え。共有原本を公開リポジトリへ同期するときは `source/game.html` へ反映し、ビルド・検証してから公開する。旧 `公開する.py` の丸ごとコピーでは入口・専用版を上書きしないこと。

Surge副配信は容量上限があるため、通常版模型の重複を入れずGitHub配信を参照する。本編で使う軽量模型は両配信先へ置く。GitHubの新しい通常模型の配信確認後にSurgeを更新する。
